Batch publishing

Bulk upload

Upload a batch of protected PDFs and a CSV that describes how each file should appear in the library.

Prepare your batch

  1. Give each PDF a clear, unique filename.
  2. Download the CSV template and add one row per study card.
  3. For a custom collection, copy the section or tile ID from Content library into the CSV’s sectionId column.
  4. Use false in the CSV’s isPublished column to create drafts, then upload the PDFs and CSV together.

The filename in the CSV must match the PDF filename exactly. A batch supports up to 10 PDFs, 25 MB per PDF and 90 MB total including the CSV. Each batch is validated as one secure operation.
